# MaTrIX Co — Gaming Browser 3.1

مشروع كامل جاهز للبناء:

    bash gradlew assembleDebug

الـ APK بيطلع في: app/build/outputs/apk/debug/app-debug.apk
(ملف gradle.properties فيه مسار aapt2 الخاص بـ AndroidIDE.)

## 3.7.0 (GX Edition + حماية)
- دمج كل مميزات النسخة القديمة في نسخة GX: فلاتر المحتوى (قوائم + كلمات + قواعد مخصصة)، حجب الإباحية بتحليل النص + البحث الآمن، قفل الإعدادات بـ PIN/بصمة، نسخ احتياطي بملف، تحديث من جوه التطبيق، شاشة تبويبات بأسلوب Brave مع وضع خاص، بناء موقّع على GitHub.
- الجدار الحديدي: تقييم خطر 0–100 بعتبة (5/15/35) ومنع تلقائي بدون سؤال، سجل منع، قائمة بيضاء من الإعدادات بس.
- HTTPS فقط (cleartext مقفول)، أخطاء الشهادات دايمًا cancel، حجب file/content/javascript/ftp/intent وأي scheme خارجي ماعدا mailto/tel/sms.
- إيماءات سحب الكروت: شمال=إغلاق، يمين=تثبيت، فوق=إغلاق+مسح بيانات الموقع، تحت=تجميد (قابلة للتغيير). التاب المثبّت مبيتقفلش بـ"إغلاق الكل".
- اقتراح تعيين المتصفح كافتراضي + زر في الإعدادات.

## 3.7.1
- إصلاح خطأ الترجمة: الدالة rgbaStr كانت ناقصة (Pages.kt بيستخدمها).

## 3.8.0 (شكل Opera + حماية البصمة)
- شكل جديد بأسلوب Opera: صفحة بداية (خلفية جبال بتدرّج غروب، شعار، شريط بحث دائري، اختصارات دائرية، بطاقات أخبار بفئات)، قايمة بمفاتيح سريعة (VPN، موفر البيانات، حاجب الإعلانات، الوضع الليلي) وبانر الشبكة، وشاشة تبويبات بنفسجي بشريط سفلي دائري.
- حماية البصمة تتحقن في بداية كل صفحة (androidx.webkit): تشويش Canvas والصوت، إخفاء اسم كارت الشاشة، توحيد الأنوية والرام والشاشة، حجب getBattery وبلوتوث/USB/Serial/HID/MIDI والحساسات، الصلاحيات الحساسة denied، إخفاء أجهزة الكاميرا/المايك، GPC وDNT، وإخفاء الخطوط غير القياسية.
- الشبكة والـ VPN: Tor عبر Orbot، بروكسي مخصص، Private DNS، وبدائل VPN مجانية موثوقة (WARP, Proton, Windscribe).
