# MaTrIX Co — Gaming Browser 3.1

مشروع كامل جاهز للبناء:

    bash gradlew assembleDebug

الـ APK بيطلع في: app/build/outputs/apk/debug/app-debug.apk
(ملف gradle.properties فيه مسار aapt2 الخاص بـ AndroidIDE.)

## 3.3
- شاشة التبويبات بأسلوب Brave: معاينة حقيقية لكل تبويب (مثبّتة من أعلى الصفحة)، بحث، اختيار متعدد، تراجع بعد الإغلاق.
- التبديل بين التبويبات العادية والخاصة؛ الشاشة الخاصة بلون بنفسجي ومعلومات عن التصفح الخاص.
- قائمة ⋮ في شاشة التبويبات: تبويب جديد، تبويب خاص، إغلاق الكل، اختيار، حذف بيانات التصفح، الإعدادات.
- عوامل تصفية المحتوى (الإعدادات ← الدرع والخصوصية): قوائم جاهزة عامة وباللغات، قوائم مخصصة برابط، وقواعد يكتبها المستخدم (حجب نطاقات + إخفاء عناصر). بتتحدث كل 24 ساعة مع قوائم الحجب.

## 3.3.1
- Porn blocker بيحجب الصفحة نفسها (مش بس الطلبات) بصفحة "الموقع ده محجوب"، وبيفرض البحث الآمن في جوجل وBing وDuckDuckGo.
- قائمة الحجب بقت StevenBlack porn-only (أصغر وبتتحمّل بثبات) + كلمات مفتاحية شغالة حتى قبل التحميل.
- القوائم المفعّلة اللي ماتحمّلتش بتتحمّل تلقائيًا أول ما تفتح شاشة عوامل التصفية.

## 3.3.2
- حجب بتحليل النص: Porn blocker بيقرا عنوان الصفحة ووصفها وعناوينها ونصها ورابطها وكلمات البحث (عربي + إنجليزي) وبيحجب أي صفحة إباحية حتى لو مش في قائمة. المواقع المؤكدة بتتحفظ وتتحجب فورًا بعد كده.
- حجب بالكلمات المفتاحية: الإعدادات ← عوامل تصفية المحتوى ← حجب بالكلمات المفتاحية (لأي موضوع).

## 3.3.3
- Porn blocker: 4 مصادر احتياطية للقائمة (بيجرب واحد ورا التاني)، وسبب الفشل بيظهر جنب القائمة.
- مفتاح "تحليل نص الصفحة (إضافي)" لو عايز القوائم بس.

## 3.4.0
- قفل الإعدادات بـ PIN (4–8 أرقام) + بصمة اختيارية: بيحمي الإعدادات ومفاتيح الدرع. الهاش PBKDF2 بملح، حد للمحاولات الغلط، "نسيت الـ PIN" بقفل شاشة الجهاز.
