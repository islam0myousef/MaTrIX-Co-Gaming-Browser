مشروع كامل جاهز للبناء:

    bash gradlew assembleDebug

## 3.7.0 (GX Edition + حماية)
- دمج كل مميزات النسخة القديمة في نسخة GX: فلاتر المحتوى (قوائم + كلمات + قواعد مخصصة)، حجب الإباحية بتحليل النص + البحث الآمن، قفل الإعدادات بـ PIN/بصمة، نسخ احتياطي بملف، تحديث من جوه التطبيق، شاشة تبويبات بأسلوب Brave مع وضع خاص، بناء موقّع على GitHub.
- الجدار الحديدي: تقييم خطر 0–100 بعتبة (5/15/35) ومنع تلقائي بدون سؤال، سجل منع، قائمة بيضاء من الإعدادات بس.
- HTTPS فقط (cleartext مقفول)، أخطاء الشهادات دايمًا cancel، حجب file/content/javascript/ftp/intent وأي scheme خارجي ماعدا mailto/tel/sms.
- إيماءات سحب الكروت: شمال=إغلاق، يمين=تثبيت، فوق=إغلاق+مسح بيانات الموقع، تحت=تجميد (قابلة للتغيير). التاب المثبّت مبيتقفلش بـ"إغلاق الكل".
- اقتراح تعيين المتصفح كافتراضي + زر في الإعدادات.
